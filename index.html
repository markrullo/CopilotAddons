Get Started

Install all four agents in a single step using the Agent Plugin format.

1 Open the VS Code Command Palette ⌘⇧P and run Chat: Install Plugin From Source
2 Paste the URL and press Enter:
https://github.com/markrullo/CopilotAddons
3 All agents install in one step. 🎉
Required VS Code settings:
  • chat.plugins.enabled
